# NDAO HIADY – AFO'KASOKA

Jeu d'action 2D pour Android, développé avec Godot 4.

## Première version
- Arène inspirée de l'Allée des Baobabs à Morondava
- Héros Afo'Kasoka
- Combat à l'épée
- Deux types d'ennemis et un boss
- Commandes tactiles et clavier
- Fonctionnement hors ligne

## Lancer le jeu
Ouvrir le dossier dans Godot 4.4 ou plus récent, puis lancer `project.godot`.

## Compilation Android
Le workflow GitHub Actions `.github/workflows/android-apk.yml` compile l'APK de débogage à chaque push sur `main` et sur demande manuelle. L'APK est publié comme artefact du workflow.

> Le premier APK est une build de développement non signée pour publication sur Google Play.
